# HW2. OOP, Testing, Git

## Описание

Проект реализует систему для работы с рецептами, ингредиентами и списком покупок.

Реализованы классы:

- `Ingredient`
- `Recipe`
- `ShoppingList`
- `DietaryRecipe`

## Структура проекта

```text
HW2/
├── ingredient.py
├── recipe.py
├── shopping_list.py
├── dietary_recipe.py
├── test_recipes.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Установка

Склонируйте репозиторий:

```bash
git clone https://github.com/re3perR/HW2_TP
cd HW2
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest
```
